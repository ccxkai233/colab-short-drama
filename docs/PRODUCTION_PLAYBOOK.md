# 🎬 从原创小说到 AI 短剧成片实战手册（Production Playbook）

本手册将你与 AI 助手的分工、小说转分镜、角色干声制作、角色 LoRA 训练与返工调优串成一条可重复落地的标准流水线。

---

## 一、人机协作分工（导演 vs 技术制片）

* **你（总导演 + 美术总监）**：
  * 守住小说的灵魂与人物气质；
  * 负责看图拍板、大胆挑毛病（直接说哪张脸不对、哪句语气不对、哪个镜头眼神不够狠）。
* **AI 助手（技术制片 + 调参工程师）**：
  * 把小说改写成短剧剧本与标准 CSV/JSON 分镜表；
  * 编写提示词、清洗训练集、生成打标 `.txt`、配置与调整 LoRA 训练超参；
  * 维护本地/云端脚本，通过 `--only-shots` 精准返工你点名的单个镜头。

---

## 二、原创小说 → 短剧剧本 → 分镜表（3 步法）

### 第 1 步：建立「角色与场景视觉圣经（Bible）」
在开工前，先为每位主要角色锁定两项永久锚点，防止多镜串脸/串音：

| 角色名 | 英文视觉锚点（每镜生图固定拼入） | 角色 LoRA（可选） | 声音母带文件名 |
| :--- | :--- | :--- | :--- |
| 林晚（女主） | `26yo Chinese woman, sleek black low ponytail, sharp almond eyes, slender` | `char_linwan.safetensors` | `voice_linwan_ref.wav` |
| 陆沉（男主） | `29yo Chinese man, short neat dark hair, defined jawline, cold gaze` | `char_luchen.safetensors` | `voice_luchen_ref.wav` |

### 第 2 步：小说章节 → 短剧分集剧本
* **单集规格**：**60 ~ 90 秒**，约 **15 ~ 25 个镜头**，总台词 **180 ~ 280 字**。
* **黄金节奏**：前 3 秒放视觉或台词强冲突钩子，结尾卡在反转或悬念点。
* **心理转视觉**：去掉长篇心理独白，改为特写动作/微表情或 1 句简短内心 OS。
* **台词切短**：每句对白控制在 **3 ~ 6 秒**，刚好匹配 Wan 2.2 单次 5 秒视频生成与 LatentSync-1.6 稳定口型区间。

### 第 3 步：拆分为两条渲染路径（省算力 + 提电影感）
每集建议 **40%~60% 对白镜 + 40%~60% 纯动作/情绪/空镜**，避免全集怼脸说话像 PPT：

1. **纯动作 / 空镜 / OS 旁白镜**：`FLUX 生首帧底图` → `Wan 2.2 14B 图生视频`
2. **正脸对白镜**：`本地 IndexTTS2 出干声` + `FLUX 首帧底图` → `Wan 2.2 14B 图生视频` → `LatentSync-1.6 对口型`

> 💡 **实操快捷方式**：直接把小说第一章发给 AI 助手，即可一键生成《角色视觉圣经》+《分集剧本》+ 可直接喂给 `scripts/batch_runner.py` 的 CSV/JSON 分镜表。

## 三、角色参考干声获取与母带规范（供本地 IndexTTS2 克隆）

### 4 种获取途径（按商用安全性排序）
1. **【商用首选】AI 语音设计（Voice Design）捏 10 秒专属母带**
   * 在 MiniMax（海螺语音）/ ElevenLabs / 阿里云百炼 CosyVoice 用人设描述词花几毛钱生成 **1 段 8~10 秒平静独白 `.wav`**；
   * 存为该角色的永久母带，整部剧全部台词与情绪后续均在本地 **RTX 5060 + IndexTTS2** 免费无限量产（零真人声音权纠纷、绝对干净无底噪）。
2. **免费开源语音集 / 过渡底声**
   * ModelScope / Hugging Face 开源纯净中文数据集（如 `AISHELL-1/3`、`MagicData`、`Common Voice`）；
   * 或先用 Edge-TTS / ChatTTS 抽好听音色生成 8 秒平静样音，再喂给 IndexTTS2 赋予影视级情绪。
3. **自录 / 朋友录 10 秒**
   * 安静房间贴近吸音物（窗帘/衣柜）录 10 秒平稳朗读，用 Audacity 或 UVR5 轻度降噪，版权完全归自己。
4. **【仅限个人练手，商用严禁】影视/有声书剥离干声**
   * 用 **UVR5（BS-RoFormer + De-Reverb）** 剥离 BGM 与混响。正式商用上线切勿克隆未经授权的真人明星或配音演员声音。

### 参考母带黄金规格（决定 IndexTTS2 音质上限）
* **时长**：**5 ~ 10 秒**最佳；
* **干净度**：单人纯干声、无 BGM、无回声、无爆麦；
* **情绪基调**：母带务必选**自然、平静、吐字清晰**的语调——不要拿歇斯底里大喊或哭腔做底声，具体情绪交给 IndexTTS2 的情感滑块/情感参考去叠加。

> 本地 Win11 + RTX 5060 部署 IndexTTS2 详见 [LOCAL_INDEXTTS2_WIN11.md](LOCAL_INDEXTTS2_WIN11.md)。

## 四、角色一致性方案与 FLUX.1-dev LoRA 制作

### 1. 何时免训练 vs 何时训 LoRA？
* **配角 / 龙套**：**不训 LoRA**，直接用云端 **`FLUX.1-Kontext (FP8)`** 拿 1 张定妆照改动作/换服装/换场景。
* **男女主角（贯穿整部剧）**：训练 1 个 **`FLUX.1-dev` 角色 LoRA**，产物（~150MB `.safetensors`）存入 `MyDrive/ComfyUI_Work/loras/`。

### 2. LoRA 底模绑定兼容铁律
* `FLUX.1-dev` 训出的 LoRA **完全兼容 `flux1-dev-fp8.safetensors`**（同架构不同精度通用）；
* **不可跨模型混用**于 `Wan 2.2`、`SDXL`、`SD 1.5`，也不建议挂在 `FLUX.1-schnell` 上；
* **好消息**：短剧通常**只需给 FLUX.1-dev 训 1 套角色 LoRA**——Wan 2.2 I2V 会锚定首帧图人脸，LatentSync-1.6 只局部重绘嘴部，二者一般都无需再单独训角色 LoRA。

### 3. 零真人素材训角色 LoRA 标准 4 步
1. **抽 1 张完美定妆照**：用 `FLUX.1-dev` 抽出最符合小说人设的高清半身/正脸图。
2. **1 变 20（裂变训练集）**：用 `FLUX.1-Kontext` 基于母图生成 **15 ~ 25 张**训练图，严格遵守「三变一不变」：
   * **不变**：五官、骨相、核心发型；
   * **必须变**：角度/景别散开（正脸、左右 45°、侧脸；特写 30% + 半身 40% + 全身 30%）、**换不同衣服、换不同背景与光线**、覆盖多种表情（防把衣服和背景焊死在脸上）。
   * **你来做导演验收**：逐张扫一遍，直接点名删掉崩脸/不像/重复的图，由 AI 助手补图。
3. **打标铁律（Captioning）**：
   * 设定唯一触发词（如 `char_linwan`）；
   * 每张图 `.txt` **详细描写会变的元素**（服装、姿势、视角、光线、背景、表情），**不反复描写固定五官**，让模型自动把“长相”绑定到触发词上。
4. **云端训练（不建议用本地 8GB 5060 硬训）**：
   * **省心方案**：Fal.ai (`flux-lora-fast-training`) / Liblib 在线上传打包图，约 10 分钟出炉；
   * **Colab Pro+ 自训方案**：使用 `ostris/ai-toolkit`（L4 24GB 开启 FP8 量化 + `low_vram`，约 30~40 分钟；A100 约 10~15 分钟）。

### 4. `ai-toolkit` 稳妥起手超参与看图诊断速查表
* **起手参数**：`linear=16`、`linear_alpha=16`、`lr=1e-4`、`optimizer=adamw8bit`、`steps=1250~1500`、每 `250` 步自动保存检查点并出固定测试样图。
* **看样图调参对照表**（你直接发样图并描述观感，由 AI 助手调参）：

| 你看到的样图问题 | 根因诊断 | 调整动作 |
| :--- | :--- | :--- |
| 整组都不太像主角 | 欠拟合 / 特征被分散 | 提高 `steps`（1500→2000）或 `rank`（16→32）；检查 `.txt` 是否误写了过多五官描写 |
| 皮肤发塑料感 / 画面变油 / 构图僵硬 | 过拟合 | 直接选用更早的 `step_750` 或 `step_1000` 权重；或降 `lr`（`1e-4`→`5e-5`）；推理时把 `strength_model` 压到 `0.75~0.85` |
| 换了提示词还是老穿训练时的衣服/背景 | 训练集服装单一或漏打标 | 剔除重复服装图并补不同穿搭图；在 `.txt` 里把训练图里的衣服/背景词补全 |
| 正脸很像但侧脸跑偏 | 训练集侧脸样本不足 | 补充 4~5 张左/右 45° 及侧脸高质量图后重训 |

## 五、成片审片与单镜头精准返工命令速查

审片发现个别镜头不满意时，只需改分镜表中对应几行的提示词 / `seed` / `lips_expression`，然后执行精准返工（不影响其他已通过的镜头）：

```bash
# 仅重跑你点名不满意的 S003 和 S007 两个镜头
python3 scripts/batch_runner.py \
  --storyboard examples/storyboard_sample.csv \
  --only-shots S003,S007 \
  --force

# 仅重试上一轮报错失败的镜头
python3 scripts/batch_runner.py \
  --storyboard examples/storyboard_sample.csv \
  --retry-failed
```
